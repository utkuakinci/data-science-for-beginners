🚢 Project: Titanic Data Analysis & Visualization

Objective: To explore the factors that influenced survival rates on the Titanic using Pandas for data manipulation and Matplotlib for visualization.

——————————————————————————————————————————

Task 1: Data Cleaning & Preprocessing

  1. Missing Value Audit: Identify columns with missing values. Handle the missing data in the Age column (e.g., fill with median) and Embarked column (e.g., fill with mode).
  2. Feature Engineering: Create a new column named FamilySize by combining SibSp (siblings/spouses) and Parch (parents/children).
  3. Data Transformation: Categorize the Age column into groups: Child (0-12), Teen (13-19), Adult (20-59), and Senior (60+).

Task 2: Survival Probability Analysis

  1. Gender Impact: Calculate the survival rate for each gender. Create a Bar Plot to visualize the disparity between males and females.
  2. Socio-Economic Status: Analyze survival rates based on Pclass (Passenger Class). Did being in 1st class significantly increase the chance of survival?
  3. Class & Gender Interaction: Create a visualization that shows survival rates segmented by both class and gender simultaneously.

Task 3: Distribution & Correlation

  1. Age Distribution: Plot a Histogram or KDE (Kernel Density Estimate) showing the age distribution of survivors vs. non-survivors.
  2. Fare Analysis: Use a Box Plot to see if passengers who paid higher fares had a better chance of survival. Identify any outliers in the Fare column.
  3. Heatmap: Generate a Correlation Heatmap of all numerical variables to find hidden relationships.

——————————————————————————————————————————

Expected Deliverables

  1. A Jupyter Notebook (.ipynb) with clean, commented code.
  2. Clear visualizations with proper titles, axis labels, and legends.
  3. A brief written summary of your 3 most important findings (e.g., "The 'Women and Children First' policy is clearly visible in the data because...").
